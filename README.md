# Basic-chatbot
A basic rule-based chatbot built with Python using functions, loops, and conditional statements.

## Description
This is a simple rule-based chatbot developed using Python. The chatbot interacts with users through predefined responses and can answer basic questions such as greetings, introduction, and simple conversations.

## Features
- Responds to greetings like "hello", "hi", and "hey"
- Answers basic questions
- Interactive conversation through user input
- Exit option using "bye"
- Console-based chatbot

## Technologies Used
- Python

## Key Concepts
- Functions
- While Loops
- If-Elif-Else Statements
- User Input/Output
- String Handling

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

bash
python chatbot.py


## Sample Conversation

text
Bot: What is your name?
User: Shivam

Bot: Nice to meet you, Shivam!

Shivam: hello
Bot: Hello! How can I help you?

Shivam: how are you
Bot: I am doing great. Thanks for asking!

Shivam: bye
Bot: Goodbye, Shivam! Have a great day.


## Project Output

- Greets users and responds to basic queries.
- Maintains a simple interactive conversation.
- Exits when the user types "bye".
